# Ticket Booking System

Pet-проект на Java — клиент-серверное приложение для работы с системой бронирования билетов.

Проект создавался для практики Java, работы с реляционной базой данных и реализации клиент-серверного взаимодействия.

## Возможности

В проекте реализованы или частично реализованы:

- регистрация и авторизация пользователей;
- поиск маршрутов;
- работа с пассажирами;
- получение данных о маршрутах и билетах;
- взаимодействие с SQLite;
- обмен данными между клиентом и сервером.

## Технологии

- Java
- Java Swing
- JDBC
- SQLite
- SQL
- Java Sockets
- многопоточность

## Архитектура

Приложение разделено на клиентскую и серверную части.

Клиентская часть содержит пользовательский интерфейс на Swing и взаимодействует с сервером через сокеты.

Сервер принимает клиентские подключения, создаёт отдельные потоки для их обработки и выполняет операции с данными.

Для хранения данных используется SQLite. Доступ к базе данных реализован через JDBC и SQL-запросы.

## Структура проекта

- `src/frontend` — пользовательский интерфейс;
- `src/backend` — модели, бизнес-логика и работа с данными;
- `src/server` — серверная часть и обработка клиентских подключений.

## Статус проекта

Проект является учебным и находится в незавершённом состоянии.

Он создавался прежде всего для практики клиент-серверной разработки, Java, JDBC и SQL, поэтому некоторые решения требуют дальнейшего рефакторинга и доработки.
